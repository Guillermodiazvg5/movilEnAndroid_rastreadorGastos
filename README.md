# Rastreador Gastos

Aplicación móvil para Android para el registro y control de gastos personales.

## 📱 Mockup
[Ver diseño en Figma](https://www.figma.com/design/dhDUFT3GzuXW99mha1TFe/Untitled?node-id=0-1&m=dev&t=fVPWpkClX4Q5BX0d-1)

## 🛠️ Tecnologías
- Kotlin
- Android Studio
- Git & GitHub

## 🎯 Objetivo
Desarrollar una app que permita a los usuarios llevar un control organizado de sus finanzas personales.
